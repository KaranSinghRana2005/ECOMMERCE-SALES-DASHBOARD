 
# 🛒 E-COMMERCE SALES DASHBOARD


An interactive and visually appealing **E-Commerce Sales Dashboard** built to analyze sales performance, profit trends, and customer insights.

## 📊 Overview

This dashboard provides a comprehensive view of:
- Total Sales Amount
- Total Profit
- Quantity Sold
- Average Order Value (AOV)
- Sales distribution by state
- Category-wise quantity analysis
- Monthly profit trends
- Customer-wise sales
- Payment mode analysis
- Sub-category profit insights

## 🚀 Features

- 📈 Dynamic and interactive visualizations
- 📅 Quarterly filter (Q1, Q2, Q3, Q4)
- 🧩 Category & sub-category breakdown
- 💳 Payment mode insights (COD, UPI, Credit Card, etc.)
- 🌍 State-wise sales analysis
- 📊 Clean UI with modern design

## 🛠️ Tools & Technologies Used

- Power BI /  Excel 
- Data Cleaning & Transformation
- Data Visualization Techniques

## 📂 Dataset

- The dataset used in this project is **open-source / publicly available**
- It includes order details, customer data, product categories, and sales metrics

## 📌 Key Insights

- Clothing category contributes the highest quantity (~63%)
- COD is the most used payment mode (~44%)
- Highest profit observed in November
- Maharashtra leads in total sales
